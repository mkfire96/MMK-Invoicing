# MMK Invoicing Pro - Fully Functional

## Features
- Dark theme dashboard
- Add/View clients
- Create/View invoices
- PDF export (placeholder)
- Gmail reminders (placeholder)
- SQLite database for persistence

## Deployment Instructions
1. Upload this repository to GitHub.
2. Connect the repo to Render.com as a Web Service.
3. Add your Gmail credentials as environment variables.
4. Deploy the app and access via browser or mobile.
